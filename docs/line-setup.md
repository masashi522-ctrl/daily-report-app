# ご家族へのLINE連絡：設定手順

連絡帳と活動写真をご家族のLINEへお送りする機能の準備手順です。
アプリ側の実装は済んでいるので、ここに書かれた設定を入れると送信が有効になります。

---

## 大前提：なぜ「LINE ID」だけでは送れないのか

利用者管理で登録する「LINE ID」は、`@` から始まる検索用のIDです。
**このIDを宛先にしてメッセージを送る方法は、LINEには用意されていません。**

送信に使えるのは、ご家族が施設のLINE公式アカウントを**友だち追加したときに発行される内部のユーザーID**（`U` で始まる33文字）だけです。
そのためアプリでは次のようにしています。

| 項目 | 役割 |
|---|---|
| LINE ID | 台帳としての控え。職員が本人確認するための情報 |
| 内部ユーザーID | 実際の送信先。友だち追加＋連携コードの送信で自動的に埋まる |

---

## 1. LINE公式アカウントを作る

1. [LINE for Business](https://www.linebiz.com/jp/) から公式アカウントを作成する（無料で作れます）
2. アカウント名は施設名にする（例：げんきむらデイサービスセンター）

## 2. Messaging API を有効にする

1. [LINE Developers コンソール](https://developers.line.biz/console/) にログイン
2. 作成した公式アカウントを Messaging API に紐づける
3. 対象のチャネルを開き、次の2つを控える
   - **チャネルシークレット**（「チャネル基本設定」タブ）
   - **チャネルアクセストークン（長期）**（「Messaging API設定」タブ → 発行）

## 3. Vercel に環境変数を登録する

Vercel のプロジェクト設定 → Environment Variables で、**Production と Preview** に登録します。
どちらも他人に見られてはいけない値なので、**Sensitive** を選んでください。

| 変数名 | 値 |
|---|---|
| `LINE_CHANNEL_ACCESS_TOKEN` | チャネルアクセストークン（長期） |
| `LINE_CHANNEL_SECRET` | チャネルシークレット |

登録して再デプロイすると、連絡帳画面の「LINEで送る」ボタンが使えるようになります。
未登録の間はボタンが押せない状態で表示され、誤送信は起きません。

## 4. Webhook を設定する

ご家族の友だち追加を受け取るために設定します。

1. LINE Developers コンソール → 「Messaging API設定」
2. **Webhook URL** に次を設定
   ```
   https://（アプリのドメイン）/api/line/webhook
   ```
3. **Webhookの利用** をオンにする
4. **応答メッセージ** をオフにする（自動応答が連携の邪魔になるため）

## 5. データベースを更新する

Supabase の SQL Editor で次のファイルの内容を実行してください。

```
scripts/sql/2026-08-21_add_family_line_contact.sql
```

利用者テーブルへの列追加と、ご家族・連携コード・送信履歴のテーブル作成を行います。
`IF NOT EXISTS` を使っているため、複数回実行しても安全です。

## 運用の流れ

### 職員の操作

1. **利用者管理**で対象の利用者を開く
2. 「ご家族への連絡（LINE）」で
   - 「ご家族への連絡を有効にする」にチェック
   - 「連絡帳を共有する」「活動写真を共有する」の必要な方にチェック
3. 「ご家族を追加」で氏名・続柄・LINE ID・電話番号を登録
4. 登録したご家族の「連携コードを発行」を押し、表示された8桁のコードをご家族に伝える

### ご家族の操作

1. 施設のLINE公式アカウントを友だち追加する
2. トークに8桁の連携コードをそのまま送る
3. 「連携が完了しました」と返信が来たら準備完了

### 送信

**連絡帳**画面で利用者を選び、「ご家族へLINEで送る」を押します。

送信されるのは、次の**すべて**を満たす利用者だけです。

- 「ご家族への連絡を有効にする」がオン
- かつ「連絡帳を共有する」または「活動写真を共有する」がオン
- かつ LINE連携済みのご家族が登録されている

有効化がオフなら、他のチェックが入っていても一切送信しません。

---

## 送られる内容

| 種類 | 内容 |
|---|---|
| 連絡帳 | その日の記録をスマホで読みやすい縦長の画像にして送ります。体温・血圧・脈拍・食事・水分・入浴・口腔ケア・お薬・排便・機能訓練と、AIが作成した「日中のご様子」を載せます |
| 活動写真 | 集計・分析画面で登録した当月の写真を送ります |

一度に送れるのはLINEの仕様で5件までです。連絡帳を優先し、残りの枠で写真を送ります。

**「特記事項」は送りません。** 職員向けのメモであり、紙の連絡帳にも印字していないためです。
ご家族にお伝えする内容は、AIがやわらかい文章に書き直した「日中のご様子」に含まれます。

---

## 注意点

- **費用**：LINE公式アカウントの無料プランでは月200通までです。それを超える場合は有料プランの検討が必要です。利用者100名×平日20日なら大きく超えるため、送る対象や頻度を決めてから運用を始めてください
- **ブロックされた場合**：ご家族がアカウントをブロックすると連携が自動的に解除され、以降は送信対象から外れます
- **機種変更のとき**：ご家族の「LINE連携を解除」を押してから、連携コードを再発行してください
- **画像の保存先**：生成した連絡帳の画像は非公開のSupabase Storageに置き、7日間有効な署名付きURLでLINEに渡しています
